# **App Name**: ngx-mat-data-grid

## Core Features:

- Data Grid Display: Display data in a grid format with column definitions.
- Sorting: Allow users to sort data by clicking on column headers.
- Filtering: Enable users to filter data using text input, dropdowns, or date pickers, configured per column. Includes a tool that helps the LLM decide the most helpful filter options, if not explicitly configured.
- Column Resizing: Allow users to resize columns by dragging column headers.
- Pagination: Implement client-side pagination with controls for page size and navigation.
- Column Visibility: Provide a mechanism for users to toggle column visibility.
- Column Reordering: Allow users to reorder columns by dragging and dropping headers.

## Style Guidelines:

- Primary color: Teal (#008080) for a professional and calming feel. NOTE: the user did not explicitly ask for Teal. Consider editing.
- Background color: Light gray (#F0F0F0) for a clean and modern look.
- Accent color: Dark blue (#00008B) for highlighting interactive elements.
- Body font: 'Inter' sans-serif for clean, readable text. NOTE: currently only Google Fonts are supported.
- Headline font: 'Space Grotesk' sans-serif for a bold and modern header style. NOTE: currently only Google Fonts are supported.
- Use Angular Material icons for sorting, filtering, and column management.
- Subtle animations for sorting and filtering transitions.
